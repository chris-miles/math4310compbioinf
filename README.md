# MATH 4310 Computational Bioinformatics

Course notes and planning materials for MATH 4310 Computational Bioinformatics.

The student-facing Quarto book lives in `course_notes/`. It is built as an HTML-only site.

## Local Preview

```powershell
quarto render .\course_notes
```

Open `course_notes/_book/index.html`.

## Public Site

The GitHub Pages workflow builds `course_notes/` and publishes the rendered HTML site.

Repository: `git@github.com:chris-miles/math4310compbioinf.git`
