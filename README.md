# MATH 4310 Computational Bioinformatics

Course notes and materials for **MATH 4310 Computational Bioinformatics** at the University of Utah, taught by Chris Miles and first offered Spring 2027. The course is an upper-division undergraduate class on the mathematics and algorithms behind modern bioinformatics — sequence alignment, assembly graphs, hidden Markov models, phylogenetics, omics matrices, clustering, and mechanistic models — emphasizing why methods work, not just how to run them.

**Read the book:** <https://chris-miles.github.io/math4310compbioinf/>

## What's in this repo

Students are welcome to browse and clone the repo directly:

- `course_notes/lessons/` — numbered Quarto lessons that make up the book.
- `course_notes/appendices/` — notation and computing conventions.
- `assignments/` — problem sets and project workshops.
- `data/` — small, public datasets used in lessons and assignments.

The syllabus will be posted closer to the start of the term.
