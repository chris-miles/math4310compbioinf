# Planning Documents

These files are instructor-facing planning notes for MATH 4310 Computational Bioinformatics.

- `course_design_memo.md`: audience, prerequisites, topic balance, and major design choices.
- `lesson_calendar.md`: 24 lessons on actual Monday/Wednesday dates, accounting for holidays, two midterms, and the project workshop.
- `homework_and_project_plan.md`: proposed weekly problem sets, final project structure, and workload controls.
- `assessment_model.md`: recommended no-final-exam assessment structure with two shorter midterms and a larger final project.
- `coding_ai_assessment.md`: coding expectations, AI policy, verification requirements, and reusable assignment template.
- `project_onramp.md`: staged plan for getting students started on final projects before they have learned the whole course.
- `reference_map.md`: books, open resources, peer-course precedents, and how to use each source.

The Spring 2027 teaching term has 27 available Monday/Wednesday meetings after holidays and spring break: 24 lessons, two midterms, and one combined project workshop/work session. The lesson shape and prose rules live in `../style/STYLE_PROSE.md`, not here.
