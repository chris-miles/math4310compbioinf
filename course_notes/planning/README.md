# Planning Documents

These files describe the course design and schedule for MATH 4310 Computational Bioinformatics. They are public in the repository, although the website does not publish them. Keep instructor-only drafts, answer keys, and source digests in ignored locations.

The website reads `../../site/schedule.json`; keep `lesson_calendar.md` consistent with it when changing meeting dates or assignment deadlines.

- `course_design_memo.md`: audience, prerequisites, topic balance, and major design choices.
- `lesson_calendar.md`: 23 lessons on actual Monday/Wednesday dates, accounting for holidays, two midterms, and two project presentation days.
- `homework_and_project_plan.md`: proposed weekly problem sets, final project structure, and workload controls.
- `assessment_model.md`: recommended no-final-exam assessment structure with two shorter midterms and a larger final project.
- `coding_ai_assessment.md`: coding expectations, AI policy, verification requirements, and reusable assignment template.
- `project_onramp.md`: staged plan for getting students started on final projects before they have learned the whole course.
- `reference_map.md`: books, open resources, peer-course precedents, and how to use each source.

The Spring 2027 teaching term has 27 available Monday/Wednesday meetings after holidays and spring break: 23 lessons, two midterms, and two project presentation days. The lesson shape and prose rules live in `../style/STYLE_PROSE.md`, not here.
