# MATH 4310 course notes

Lecture notes are written in Markdown and published as HTML on the [course website](https://chris-miles.github.io/math4310compbioinf/).

- **lessons/**: numbered lecture sources. Set published: true when a lecture is ready to appear as a link.
- **appendices/**: computing conventions, math refreshers, and notation.
- **using-notes.md**: guidance for reading the notes and working with examples.
- **style/**: the prose, code, figure, and schematic conventions and shared plotting helpers.
- **references.bib**: citations used in the notes.

The homepage and weekly schedule live in site/. See [authoring and publishing](../site/AUTHORING.md) for the build commands and markup conventions. Existing mathematical content and plotting conventions are unchanged by the switch from Quarto to HTML templates.
