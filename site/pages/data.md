The first dataset is the 5,386-base [phiX174 reference genome](data/phix174-NC_001422.1.fasta), from [NCBI RefSeq, NC_001422.1](https://www.ncbi.nlm.nih.gov/nuccore/NC_001422.1). It supports k-mer counting and small assembly experiments. It is a reference sequence, not sequencing reads or a CpG-island benchmark.

The genome is circular; the file is a linear representation. The introductory code omits words crossing the file boundary. Source details, checksums, and counting conventions are in the [data README](https://github.com/chris-miles/math4310compbioinf/blob/main/data/README.md). Problem Set 1 uses only the short strings printed in the problems.
